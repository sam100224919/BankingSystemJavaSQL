# Banking Management System

A console-based Java application integrated with a MySQL database via JDBC, featuring secure account creation, balance checks, deposits, withdrawals, and transaction logging.

## Technologies Used
* **Java** (Object-Oriented Programming, Collections, Exception Handling)
* **MySQL & JDBC** (Database Design, Prepared Statements, Foreign Key Constraints)
* **IntelliJ IDEA**
